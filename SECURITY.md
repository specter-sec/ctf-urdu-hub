# Security policy

## Scope

This project is a static documentation site and a set of offline educational fixture generators. Security reports may cover unsafe code in this repository, unintended network activity, path traversal or writes outside `labs/work/`, secret exposure in committed project files, or a vulnerability in the build/deploy workflow that affects this repository.

Third-party sites, CTF platforms, user devices, unrelated GitHub repositories, and live infrastructure are out of scope. Do not scan or test them on the basis of this policy.

## Reporting a vulnerability

Please use GitHub's **Report a vulnerability** / private security advisory feature for this repository when available. If it is unavailable, privately contact the maintainers using the security contact listed on the repository profile. Include the affected commit or file, impact, safe reproduction steps using local files, and any suggested fix. Please do not include personal data or exploit a real third-party system to demonstrate a report.

Please allow maintainers reasonable time to investigate and coordinate a fix before public disclosure. This project does not promise a specific response time or bounty. For urgent risk to a person, contact the relevant service owner or local emergency/support resource instead of posting details publicly.

## Supported versions

Only the current default branch is maintained. As a small educational project, the repository does not guarantee security support for older commits or third-party dependencies beyond their upstream support lifecycle.
