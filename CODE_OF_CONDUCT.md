# Contributor Code of Conduct

## Our commitment

We want CTF Urdu Hub to be a welcoming, respectful learning space for people with different backgrounds and experience levels. Har contributor, reviewer, and community member se professional, considerate aur inclusive rawayya expect kiya jata hai.

## Expected behavior

Use welcoming language; critique ideas and code rather than people; explain disagreements constructively; respect privacy and attribution; accept feedback gracefully; and keep security discussion within the project's authorized, educational scope.

## Unacceptable behavior

Harassment, discrimination, threats, sexualized attention, doxxing, deliberate disruption, plagiarism, publishing private information, or encouraging unauthorized testing is not acceptable. Follow the project's [ethics and safety boundaries](docs/ethics.md).

## Reporting and enforcement

Report a concern privately to the repository maintainers through the contact channel listed in the GitHub repository profile or its security advisory form. Include enough context to investigate; do not post private information in a public issue. Maintainers will review reports promptly and fairly, protect reporter confidentiality where practical, and may edit or remove content, limit participation, or block a contributor. Retaliation for a good-faith report is not acceptable.

This policy applies to project spaces and public representation of project members in project-related spaces. Adapted in spirit from the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) version 2.1; this project does not claim Contributor Covenant certification.
