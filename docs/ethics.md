# Ethics & Safe Practice

Cybersecurity ka hunar tabhi useful hai jab us ke saath consent aur zimmedari ho. Is project ke practice fixtures fictional hain aur local machine par generate hote hain; kisi live service ko test karna in exercises ka hissa nahi.

## Har exercise se pehle

1. **Scope likho:** kis lab/file/system ko test karne ki ijazat hai, aur kya mana hai?
2. **Authorization confirm karo:** sirf apne systems, purpose-built practice environments, ya explicit permission wale targets par kaam karo.
3. **Data minimize karo:** real logins, personal data, ya private files collect/share na karo.
4. **Safe boundaries rakho:** disruption, persistence, stealth, credential theft, aur public-target scanning is curriculum ka maqsad nahi.
5. **Safely report karo:** agar kisi real exposure ka ittefaqan pata chale, details ko public karne ke bajaye owner ke published security-contact process ko follow karo.

> Is documentation se kisi particular activity ki legal approval nahi milti. Qanoon aur rules ilaqe aur platform ke mutabiq badalte hain; current rules aur authorization khud verify karo.

## Is hub ki boundaries

- Labs synthetic, deterministic, offline practice data banate hain.
- Demo markers sirf `CTFURDU{...}` family ke fictional strings hain; yahan real challenge flags ya credentials nahi hain.
- Link ki gayi third-party learning sites apni policies aur terms rakhti hain. Unke sirf authorized practice areas use karo.
- Yeh hub kisi vendor, CTF platform ya security product se affiliated nahi.
