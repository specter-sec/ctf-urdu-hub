# Web

Web challenges mein browser, HTTP aur application behavior ko samajhna kaam aata hai. Pehle request/response aur page structure dekho; kisi public website par probe ya scan karne ki zaroorat nahi.

## Safe beginner exercise

[Web Source Pehchano](../writeups/web/source-pehchano.md) ka fictional page banao aur local HTML source ko apne editor ya `grep` se inspect karo. Page ke comment mein rakhe demo clue ko dhoondo; apne alfaaz mein samjhao ke browser se source dekhna aur server ko test karna alag cheezein hain. [Local lab source](https://github.com/specter-sec/ctf-urdu-hub/blob/main/labs/web-source.py) network access use nahi karta.
